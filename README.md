# Bug Tracker

Система трекинга багов в студенческих проектах. Команда №22.

## Как запустить

### База данных

1. Скопируйте `.env.example` в `.env` и задайте свой пароль.
2. Запустите Docker Desktop.
3. В корне репозитория выполните: `docker compose up -d`

**Порт базы данных.** В `docker-compose.yml` внешний порт PostgreSQL указан **5433** (`"5433:5432"`), а не стандартный 5432. Так сделано, потому что на многих компьютерах уже установлен свой PostgreSQL, который занимает порт 5432, и приложение подключалось бы к нему вместо Docker (ошибка `28P01`: пароль не подошёл).

- Строка подключения в `appsettings.json` должна содержать `Port=5433`.
- В Rider (вкладка Database) подключайтесь к `localhost:5433`.
- Если порт 5433 у вас тоже занят, поменяйте левое число в `docker-compose.yml` (например, на `5434`) и то же число в строке подключения.
- Если вы меняли пароль в `.env` после первого запуска, пересоздайте базу: `docker compose down -v`, затем `docker compose up -d` (данные при этом удаляются).

### Бэкенд

1. Откройте папку `backend/` в Rider.
2. Запустите проект API.
3. Swagger открывается по адресу, который покажет Rider при запуске (обычно `/swagger`).

### Фронтенд

1. Перейдите в `frontend/`.
2. Выполните `npm install`, затем `npm run dev`.

## Работа с ветками

- `main` — стабильная ветка, напрямую не пушим, только через pull request.


Каждый pull request проверяет минимум один человек из команды.
